# OKF Knowledge Catalog Skill Design

Local-first skill for creating and consuming Open Knowledge Format bundles. Main skill routes authoring, memory capture, inspection, search, validation, repair, indexing, logging, and visualization. Heavy format rules live in reference file. Source adapters stay pluggable; files and repositories ship first.

Skill treats notes, decisions, runbooks, troubleshooting discoveries, and durable agent memories as concepts. It favors one canonical concept, source provenance, links instead of duplication, progressive disclosure, and review before destructive or broad edits.

Source: GoogleCloudPlatform/knowledge-catalog, Apache-2.0.
